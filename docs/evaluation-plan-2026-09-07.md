# 목표 및 진행 계획 — 2026-09-07

## 목표와 현재 상태

Codex가 로컬 실행과 검증을 맡고 Notion AI가 독립된 UI 채팅에서 분석·코드 제안을 수행한다. 개인 인증 MCP는 프로젝트 소스 및 허용된 Codex 지침만 읽는다. 앱만 허용했던 초기 조건은 이후 사용자 승인으로 브라우저 UI까지 확대됐다.

로컬 브로커·모델 검증·세션 계약을 구현했고, 개인 OAuth 및 실제 프로젝트/지침 읽기 E2E를 완료했다. 전체 병렬 오케스트레이션은 아직 미완료다. 최신 순서와 중단 조건은 [남은 작업 실행 계획](remaining-work-plan.md)을 따른다.

## 완료 증거

- 코드와 목표 사이의 차이 및 우선순위를 기록한다.
- 브로커의 경로·민감 파일·링크·출력 한도·인증 거부와 허용을 검증한다.
- AI 호출의 모델별 effort, 오류 처리, 응답 추출을 검증한다.
- 독립 세션 식별, 동시성 제한, 중복/불명확 전송, 결과 출처를 검증한다.
- 로컬 테스트, 실제 UI 실행, Cloudflare 인증, Notion 원격 읽기를 구분한다. 미수행 단계를 완료로 표시하지 않는다.

## 진행 이력

1. 기존 미커밋 브로커를 보존하며 파일 접근·HTTP 인증·모델/스트림·세션 기능을 보완했다.
2. 합성 루프백과 회귀 테스트 후 안전한 UI 입력 대상을 점검했다. 앱 잠금/입력 제어 문제로 자동 UI 실행은 보류했다.
3. 사용자 승인으로 전용 Cloudflare 원본/개인 Portal 및 Notion 개인 OAuth 연결을 완료했다.
4. 브라우저 직접 실행 승인 후 합성 파일을 읽고 로컬 본문/digest와 대조했다.
5. 사용자 요청으로 실제 프로젝트 루트로 전환하고 scope mode/실제 경로를 응답에 추가했다. 실제 파일·전역 지침·스킬 해시를 대조했다.
6. 사용자 요청으로 README·현재 계획·공개용 증거를 정리하고, 검증한 변경의 커밋·푸시를 진행한다.

## 범위

파일 쓰기/shell 실행을 원격 MCP에 노출하지 않는다. 세션 checkpoint와 credential은 외부 공유하지 않는다. 기존 서비스·다른 프로젝트·사용자 초안을 보존한다. 로컬 실행기와 새 UI 계약의 실제 연결, 병렬 모델 벤치마크, 전체 적용/복구 루프는 후속 작업이다.
